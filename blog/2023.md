# 2023，重新出发

这是一个用于展示页面效果的占位文档。你只需要在 `blog` 文件夹中新增以四位年份命名的 Markdown 文件，它就会成为时间轴上的新节点。

## Markdown 示例

普通文本支持 **粗体**、*斜体*、~~删除线~~、[链接](https://haruko386.github.io) 与 `行内代码`。

### 原生 HTML

Markdown 中也可以直接嵌入 HTML：

<details>
  <summary>展开一段被折叠的回忆</summary>
  <p style="margin-top: 1rem; color: var(--muted);">这里可以放照片、补充说明，或任何你想保留的内容。</p>
</details>
